# slag
**S**oftware **L**ibrary for **A**ccompaniment **G**eneration 

Python 2 library for generating harmonic accomponiment to melody.

For details, see [**Automatic musical accompaniment using finite state machines**](https://www.proquest.com/openview/400a792d1204ab6e6390539f7ba6c0e7/1?pq-origsite=gscholar&cbl=18750) (Forsyth, 2016)
